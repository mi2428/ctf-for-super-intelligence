# Silent Orchestra

> Do not guess the one song you heard. Recover every song the silence concealed.

There are three instruments and a sealed score. Their observations are exact, but incomplete.
Each sub-challenge asks for **every candidate satisfying its conditions**. One witness is not a sub-flag.

## Distribution and rules

- This directory is self-contained. The inputs are in `instruments.json`; the sealed finale is in `finale.seal.json`.
- Verification requires Python 3.10 or newer and its standard library only. No network, extra packages, or enormous computations are needed.
- You may write any programs you like. You may inspect `verify.py`, but modifying the distribution does not count as solving it.
- `answers/`, Git history, and the author's working files are not part of the distribution. Brute-forcing the verifier's hashes is not the puzzle.
- Collect all three sub-flags before opening the finale. Submit every sub-flag, the final flag, and your solution method.

## Common recording rule M

Record each element of a finite set `S` as the ASCII string specified by its sub-challenge.
Remove duplicates, sort in ASCII lexicographic order, and **append one LF to every line**, including the last.
Do not insert blank lines. The empty set is encoded as zero bytes.
Let `H` be the SHA-256 digest of these bytes, written as 64 lowercase hexadecimal digits.
Let `N` be the set's cardinality in decimal, without leading zeros.

For example, `S = {"ba", "ab"}` is hashed as exactly `b"ab\nba\n"`.

The sub-flag for instrument `name` is `SUB{name:N:H}`, where `name` is `echo`, `chamber`, or `canon`.
Braces, colons, and letter case are literal parts of the format.

## I — Echo: a melody without a starting point

The `echo` object specifies `length = 32`, `width = 6`, and an observed `deck`.

A candidate is a cyclic binary word `w` of length 32. Positions run from 0 through 31; read all indices modulo 32.
At each position `i`, take the six bits `w[i]w[i+1]...w[i+5]`, producing 32 cards.
The `deck` maps each card string to its multiplicity. Find every cyclic word whose cards match it **exactly, including multiplicities**.

Identify rotations only. Do not identify reversal or exchanging 0 and 1.
Record each rotation class as the lexicographically smallest 32-bit string among all its rotations.
Apply M to obtain `SUB{echo:N:H}`.

## II — Chamber: an echo without phase

The vertices of `chamber` are `0` through `vertices - 1`.
The `edges` array is ordered, but its edges are undirected. Assign each edge a sign of `+1` or `-1`.
The symmetric matrix `A` has that sign on each edge and zero elsewhere; its diagonal is zero.
The observed `moments[r]` is `tr(A^r)` for `r = 0,...,6`.
Find every matching sign assignment. There are no conditions on powers 7 or higher.

Identify two assignments if choosing arbitrary vertex signs `d_v ∈ {+1,-1}` and replacing each edge sign
`s_uv` by `d_u s_uv d_v` transforms one assignment into the other.
Vertex names are fixed: do not identify assignments under vertex permutations.

Encode an assignment as a 19-bit string in `edges` order, using `+1 → 0` and `-1 → 1`.
Record each equivalence class once, as the lexicographically smallest string in that class.
Apply M to obtain `SUB{chamber:N:H}`.

## III — Canon: silent in another world?

Words in `canon` use the alphabet `a, A, t, T`. Here `A` is the inverse of `a`, and `T` is the inverse of `t`.
Write `ε` for the empty word. Word equivalence is **exactly the relation generated by these rules**:

1. Insert or delete `aA`, `Aa`, `tT`, or `Tt` anywhere in a word.
2. Replace any substring `taaT` with `aaa`, or make the reverse replacement.

There is no limit on the number of rule applications or the lengths of intermediate words.
From the 16 supplied words, record the **two-digit `id`** of each word equivalent to the empty word.
Keep leading zeros in IDs. Apply M to obtain `SUB{canon:N:H}`.

For reference, the rules are consistent with the rational affine maps `a(x)=x+1` and `t(x)=3x/2`.
If using maps, read a word `uv` as `f_u ∘ f_v`, with the right-hand map acting first.
**Equivalence is defined by the two rules above. Equality of maps must not be added as another rule.**

## IV — Finale: the sealed score

The score is sealed under a key depending on all three correct sub-flags.
Once you have them, the bars and the finale's rules are displayed as JSON.
Breaking the seal's cryptography is not the challenge. The final flag has the form `FLAG{silent-orchestra:N:H}`.

Run the following commands with this directory as your working directory.

```sh
python3 -B verify.py sub echo 'SUB{echo:N:H}'
python3 -B verify.py sub chamber 'SUB{chamber:N:H}'
python3 -B verify.py sub canon 'SUB{canon:N:H}'
```

Create `keys.json` containing your actual flags in **echo, chamber, canon order**.
The strings below are explanatory placeholders, not answers.

```json
[
  "your echo sub-flag",
  "your chamber sub-flag",
  "your canon sub-flag"
]
```

```sh
python3 -B verify.py open keys.json
python3 -B verify.py final keys.json 'FLAG{silent-orchestra:N:H}'
```

Both `open` and `final` validate all three keys. Missing, reordered, or incorrect keys are rejected.
The `sub` and `final` commands print `OK` and exit with code 0 on acceptance, or exit with code 1 on rejection.
The `open` command displays the score as JSON on success. Invalid command syntax exits with code 2.
