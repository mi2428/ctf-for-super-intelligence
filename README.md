# CTF Challenges for Super Intelligence Agents

Distribute only the challenge directory to challengers. `answers/` contains organizer-only solutions and reproducibility checks.


| Challenge | Domain | Structure |
| --- | --- | --- |
| [Cold Garden](gpt-5.5-xhigh-cold-garden/) | Combinatorial game theory, dyadic rationals, recursive search | Three sub-challenges and a sealed final grove requiring every sub-flag |
| [The False Ledger](gpt-5.6-sol-max-false-ledger/) | Inconsistent databases, maximal repairs, query lineage | Three quantified sub-challenges and a sealed robust-deletion audit requiring every sub-flag |
| [The Last Parser](gpt-6-luna-max-the-last-parser/) | Formal language semantics | Three subchallenges: precedence, associativity, and composition; then a sealed final expression |
| [Blind Atrium](gpt-6-astra-max-blind-atrium/) | Imperfect-information games, temporal logic, controller synthesis | Three subchallenges and a final controller task sealed by all three sub-flags |
| [Silent Orchestra](gpt-6.1-sol-max-silent-orchestra/) | Combinatorics, signed graphs, noncommutative rewriting | Three sub-challenges and a finale requiring every sub-flag |
| [Folded Tribunal](gpt-6.1-sol-max-folded-tribunal/) | Infinite rational languages, nonabelian transport, partial-observation control | Three records and a sealed universal hearing/patrol requiring exact automata, a memory-optimal controller, and a structural lower bound |
